# Kanban Board

A creative Kanban board built with **Nuxt 3** and **Bootstrap 5**. Dark theme with glassmorphism-style columns, drag-and-drop cards, and local storage persistence.

## Features

- **4 columns**: To Do, In Progress, Review, Done
- **Drag and drop** cards between columns
- **Add / Edit / Delete** tasks with a modal form
- **Priority** (Low, Medium, High) and optional description
- **Auto-save** to `localStorage` so your board persists across sessions
- **Responsive** grid layout (Bootstrap + custom CSS)
- **Outfit** font and cyan/teal accent theme

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` – Start development server
- `npm run build` – Build for production
- `npm run preview` – Preview production build

## Stack

- Nuxt 3
- Vue 3
- Bootstrap 5 + Bootstrap Icons
- TypeScript
